# 이화 공동구매 플랫폼

> 이화인을 위한 간편 공동구매 플랫폼

이화여자대학교 재학생들이 공동구매 상품을 탐색하고, 함께 구매할 사람을 모으며, 참여 현황과 진행 상황을 한곳에서 확인할 수 있도록 기획한 웹 서비스입니다.

**서비스명은 추후 확정 예정이며, 아래 기능은 현재 기획 중인 개발 목표입니다.**

## 1. 서비스 개요

| 항목 | 내용 |
| --- | --- |
| 서비스 유형 | 공동구매 마켓 |
| 대상 이용자 | 이화여자대학교 재학생 전체 |
| 핵심 가치 | 공동구매 상품 탐색부터 참여 및 진행 상황 확인까지 하나의 웹사이트에서 처리 |
| 주요 개발 방향 | 공동구매 참여 절차를 간소화하고, 같은 상품을 원하는 이용자들이 함께 구매할 수 있도록 연결 |

## 2. 기획 배경

개인이 공동구매를 진행할 때는 상품을 찾은 뒤 참여자를 모집하고, 참여 인원과 금액을 취합하며, 진행 상황을 별도로 안내해야 합니다. 참여자 역시 여러 게시글이나 대화를 확인해야 하므로 공동구매 정보를 파악하고 참여하는 데 번거로움이 있습니다.

이 서비스는 이러한 과정을 하나의 웹사이트로 모아, 공동구매를 진행하는 사람과 참여하는 사람 모두의 부담을 줄이는 것을 목표로 합니다.

## 3. 서비스 이용 흐름

1. **상품 탐색**: 진행 중인 공동구매 상품을 확인합니다.
2. **공동구매 참여**: 원하는 상품의 공동구매에 참여합니다.
3. **참여 현황 확인**: 모집 인원, 금액 및 목표 달성 현황을 확인합니다.
4. **진행 상황 확인**: 참여한 공동구매의 진행 상태를 확인합니다.

향후에는 같은 상품을 원하는 이용자들을 웹사이트 내에서 자동으로 연결하여, 함께 공동구매할 사람을 직접 찾는 수고를 줄일 계획입니다.

## 4. 차별화 방향

| 기존 개인 주도 공동구매에서의 번거로움 | 서비스가 지향하는 개선 방향 |
| --- | --- |
| 상품 탐색과 참여자 모집을 각각 진행 | 상품 확인과 공동구매 참여를 한곳에서 제공 |
| 함께 구매할 사람을 직접 찾아야 함 | 같은 구매 수요를 가진 이용자를 플랫폼 내에서 연결 |
| 인원과 금액을 별도로 취합하고 확인 | 공동구매별 참여 인원과 금액을 웹사이트에서 확인 |
| 진행 상황을 개별적으로 문의하거나 안내 | 참여한 공동구매의 진행 상태를 웹사이트에서 확인 |

이화여자대학교 재학생을 대상으로 하여, 이화인들의 공동구매 수요를 한곳에 모으는 마켓을 지향합니다.

## 5. 기획 기능 및 개발 범위

### 기본 마켓 구성

- **메인 및 공통 내비게이션**: 주요 페이지에 쉽게 접근할 수 있는 메뉴 제공
- **상품 등록 및 목록**: 공동구매 상품 정보를 등록하고 확인하는 화면 구성
- **리뷰 등록 및 목록**: 상품에 대한 이용자 후기를 작성하고 확인하는 화면 구성

초기에는 기본 페이지와 상품 정보 입력·전송 기능부터 구현하고, 공동구매 특화 기능은 이후 단계에서 개발할 예정입니다.

### 공동구매 특화 기능 — 후속 개발 예정

| 기능 | 기획 내용 |
| --- | --- |
| 수요자 자동 매칭 | 같은 상품의 공동구매를 원하는 이용자들을 자동으로 연결 |
| 참여 및 현황 확인 | 공동구매에 참여하고 모집 인원과 금액을 확인 |
| 목표 및 진행률 표시 | 공동구매 목표와 현재 달성 정도를 표시 |
| 달성 알림 | 공동구매 목표가 달성되면 참여자에게 알림 제공 |
| 장바구니 및 구매 | 원하는 상품을 담고 구매 절차를 진행할 수 있는 기능 제공 |

구체적인 매칭 방식, 목표 기준, 알림 방식 및 구매 처리 방식은 후속 기획에서 결정할 예정입니다.

## 6. 취급 상품 후보

공동구매를 중심으로 다음 상품군을 검토하고 있습니다. 최종 취급 상품은 추후 확정할 예정입니다.

- **공동구매 상품**: 여러 재학생이 함께 구매할 수 있는 상품
- **자체 제작 상품**: 종합 선물세트 등 자체 기획·제작 상품
- **축제 상품**: 축제 관련 굿즈

## 7. 기대 효과

- **참여 편의성 향상**: 상품 탐색부터 참여와 진행 상황 확인까지 필요한 정보를 한곳에서 제공
- **운영 부담 감소**: 참여자 모집 및 인원·금액 확인에 드는 수고를 줄임
- **공동구매 접근성 향상**: 함께 구매할 사람을 찾기 어려운 재학생도 공동구매에 참여할 수 있도록 지원
